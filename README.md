## Android — Add to Home screen

1. Open the board URL in **Chrome** on Android.
2. Tap the **⋮** menu (top right).
3. Tap **Add to Home screen** (or **Install app**).
4. Confirm (**Stable**) → **Add**.
5. Launch from the home-screen icon.
